## API Reference

### Separator

| Prop          | Type                         | Default        | Description                         |
| ------------- | ---------------------------- | -------------- | ----------------------------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | The orientation of the separator    |
| `decorative`  | `boolean`                    | `true`         | Whether the separator is decorative |
